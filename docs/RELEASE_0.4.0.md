# v0.4.0 验收

新增可选 OpenRouter 免费模型交叉验证，默认关闭。此版本发布原有规则监测与可选复核入口，实际在线模型质量仍需用户授权后验证。

## 状态与操作门禁

本机用户可查看所有状态；模型服务仅收到授权范围内的公开原帖，不接收规则结果或账户数据。

| 状态 | 允许的操作 | 门禁与结果 |
| --- | --- | --- |
| 未启用 | 阅读说明、输入 Key、切换语言 | 未勾选授权时“授权并启用”禁用；不访问模型 |
| 验证中 | 查看状态 | 禁止重复提交与凭据修改；验证成功后才保存 Key 并启用 |
| 等待新帖 / 待分析 | 停用、查看记录 | 仅已授权且有 Key 时处理最近 24 小时原帖；不按 reset 关键词筛选 |
| 分析中 | 查看原帖、停用 | 独立于规则提醒；停用取消后续处理并忽略迟到响应 |
| 结论一致 | 查看结果 | 不额外弹窗，保留原有提醒 |
| 疑似漏报 / 分歧 | 查看依据、确认已读 | 明确 AI 候选才弹复核窗口，无声音；不能据此确认账户重置或生成倒计时 |
| 分析失败 | 查看原因、有限重试 | 原帖已抓取与 AI 失败分开显示；同一版本最多两次分析尝试 |
| 限流 / 本地请求上限 | 查看、停用 | 服务 Retry-After 与每滚动 24 小时 20 次上限不可通过手动重试或重新授权绕过 |
| 授权失效 | 重新授权、停用、移除 Key | 不再发模型请求；原有规则监测继续 |
| 移除 Key | 取消或确认移除 | 二次确认；停用并删除本机凭据，不删除事件或历史记录，不撤销网站 Key |

缓存以帖子 ID、原文、日期、直接回复上文、提示版本计算指纹。未修改的帖子刷新/重启不重复分析；规则升级仅重新比较已有 AI 结果。AI 输出须通过 JSON、枚举、原文引用、原文时间和截断校验。固定免费路由，无模型候补列表、工具、付费模型或网页插件。凭据仅存 Keychain；网络错误不回显服务器原文或 Key；生产客户端拒绝重定向。

## 未验证边界

没有配置真实 OpenRouter Key，因此未进行真实模型请求，未验证在线模型准确率、延迟或用户机器上的 Keychain 读写授权。模型判断用模拟响应验证的是应用行为，而非模型自身的语言理解质量。当前免费路由会动态选择模型，需在用户授权后用历史漏报、误报原帖做在线验收。不能保证转引源不缺帖，也不会查询用户真实额度。

真实凭据需用户在本机安全输入框授权配置，不通过聊天、命令行参数或源码传递。
