## 失败原因与边界

本机旧记录有3次笼统校验失败、1次连接失败；旧版未保存响应结束原因，无法断言前三次究竟属于截断、格式还是依据问题。本版区分这些错误，并仅保存有限的HTTP状态、结束原因及用量数字，不保存Key、服务器错误原文或模型思考。

OpenRouter官方说明思考与回答通常共享输出预算，可能出现回答长度耗尽。本版将输出上限由1200调整为4096并请求低思考强度，降低此类风险；这不是对历史3次失败原因的确证，也不保证免费服务永不失败。

未为本次验收额外重试耗尽的旧失败项，未进行新一轮真实模型生成。因此新的错误分类及请求参数由模拟服务验证，实际免费模型的后续稳定性仍需运行观察。原有授权、缓存及历史不被重置。

AI待核对仍为独立复核，未据此创建已确认事件或倒计时。确认阅读、停用或原帖24小时过期后取消提示；有明确AI候选的新发现仍会弹出复核窗口，无提示音。公开转引覆盖、个人账号实际额度和Developer ID签名/公证不在本次验证范围。
